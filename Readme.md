Deep Learning Skills Tracker
A comprehensive collection of deep learning tasks and exercises designed to build and strengthen skills in PyTorch and neural networks.

Project Structure
This project contains 15 tasks covering various deep learning concepts:

Task 1-5: Fundamentals of PyTorch and neural network basics
Task 6-10: Advanced model architectures and training techniques
Task 11-15: Distributed training, optimization, and production-ready implementations

Installation
Clone this repository:
git clone https://github.com/yourusername/deep_learning_skill_tracker.git
cd deep_learning_skill_tracker
Create a virtual environment:
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
Install dependencies:
pip install -r requirements.txt
Usage
Open any notebook in Jupyter:

jupyter notebook task1.ipynb
Or use VS Code with the Jupyter extension installed.
